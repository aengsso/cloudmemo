CloudMemo 개인정보처리방침

시행일: 2026년 11월 16일

1. 어떤 정보를 쓰나요

CloudMemo는 사용자가 직접 쓴 메모와 일기를 사용자 본인의 Google 드라이브에 저장하고 불러오기 위해서만 Google 계정에 접근합니다. 요청하는 권한은 drive.file 하나뿐이며, 이 권한으로는 CloudMemo가 직접 만든 파일만 볼 수 있고 드라이브의 다른 파일은 볼 수 없습니다.

2. 어디에 저장되나요

메모는 사용자 Google 드라이브의 "CloudMemo" 폴더와, 사용자 기기(브라우저 저장소 또는 PC의 앱 폴더)에만 저장됩니다. CloudMemo는 별도의 서버를 운영하지 않으며, 개발자를 포함한 누구에게도 메모 내용이나 계정 정보가 전송되지 않습니다.

3. 비밀 폴더와 잠긴 일기

비밀번호로 잠근 메모는 기기 안에서 AES-256으로 암호화된 뒤 드라이브에 올라갑니다. 비밀번호는 어디에도 저장되지 않으며, 잊어버리면 복구할 수 없습니다.

4. 제3자 제공

수집한 정보를 판매하거나 제3자에게 제공하지 않습니다. 광고나 분석 도구도 쓰지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 삭제와 접근 해제

앱에서 메모를 지우면 드라이브의 해당 파일이 휴지통으로 이동합니다. 언제든 Google 계정의 서드파티 액세스에서 CloudMemo의 접근 권한을 해제할 수 있습니다.
