CloudMemo 개인정보처리방침

시행일: 2026년 11월 26일

1. 어떤 정보를 쓰나요

CloudMemo는 사용자가 직접 쓴 메모와 일기를 사용자 본인의 Google 드라이브에 저장하고 불러오기 위해서만 Google 계정에 접근합니다. 기본으로 요청하는 권한은 drive.file 하나뿐이며, 이 권한으로는 CloudMemo가 직접 만든 파일만 볼 수 있고 드라이브의 다른 파일은 볼 수 없습니다. 사용자가 일기에서 구글 캘린더 연결을 직접 켠 경우에만 캘린더 일정을 읽고(calendar.readonly), 사용자가 추가한 일정을 캘린더에 넣습니다(calendar.events). 캘린더 정보는 화면에 보여 주는 데만 쓰고 따로 저장하지 않습니다.

2. 어디에 저장되나요

메모는 사용자 Google 드라이브의 "CloudMemo" 폴더와, 사용자 기기(브라우저 저장소 또는 PC의 앱 폴더)에만 저장됩니다. CloudMemo는 별도의 서버를 운영하지 않으며, 개발자를 포함한 누구에게도 메모 내용이나 계정 정보가 전송되지 않습니다.

3. 비밀 폴더와 잠긴 일기

비밀번호로 잠근 메모는 기기 안에서 AES-256으로 암호화된 뒤 드라이브에 올라갑니다. 비밀번호는 어디에도 저장되지 않으며, 잊어버리면 복구할 수 없습니다.

4. 일기 날씨

설정에서 날씨 위치를 고른 경우에만, 일기에 날씨를 넣기 위해 Open-Meteo에 도시 이름(검색할 때)과 그 위치의 좌표, 날짜를 보냅니다. "현재 위치"를 쓰면 기기의 위치를 약 1km 단위로 반올림한 좌표만 보냅니다. 메모 내용이나 계정 정보는 보내지 않으며, 고른 위치는 그 기기에만 저장됩니다.

5. 제3자 제공

수집한 정보를 판매하거나 제3자에게 제공하지 않습니다. 광고나 분석 도구도 쓰지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 삭제와 접근 해제

앱에서 메모를 지우면 드라이브의 해당 파일이 휴지통으로 이동합니다. 언제든 Google 계정의 서드파티 액세스에서 CloudMemo의 접근 권한을 해제할 수 있습니다.
